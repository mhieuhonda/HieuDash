# Sprite Frame Names (v0.4)

Complete list of every sprite-frame name referenced by Hieu Dash C++
code, sourced from the GD-Decompiled reference snapshot in
`gd_reference/src/`. These names are passed to
`CCSprite::createWithSpriteFrameName("…")` at runtime and are resolved
against frames defined inside the following sprite-sheet `.plist` files:

- `GJ_GameSheet.plist` (loaded by `GJBaseGameLayer::init`)
- `GJ_GameSheet02.plist` (loaded by `GJBaseGameLayer::init` — **missing**, see RESOURCE_MANIFEST.md)
- `GJ_LaunchSheet.plist` (loaded by `AppDelegate::applicationDidFinishLaunching`)
- `GameSheetGlow.plist` (**missing**, see RESOURCE_MANIFEST.md)
- `FireSheet_01.plist` (**missing**, see RESOURCE_MANIFEST.md)

Frame names are grouped by their primary in-game object family.
