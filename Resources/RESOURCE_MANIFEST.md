## How to fill the gaps

1. Obtain the original Geometry Dash 1.0 APK
   (`com.robtopx.geometryjump`, August 2013 build).
2. Extract it with `apktool d GeometryDash.apk`.
3. Copy every file from `assets/Resources/` into this directory.
4. Re-run `python3 scripts/gen_resource_manifest.py` to verify the
   missing-file lists above are now empty.
5. Rebuild the project (`./proj.android/build_native.sh`).

> **Note:** the GD-Decompiled reference repo does NOT ship any
> binary assets — it is purely a code reference. So the missing
> files above cannot be copied from `gd_reference/`; they must be
> sourced from the original APK.
